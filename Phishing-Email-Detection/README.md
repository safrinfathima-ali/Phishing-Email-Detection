
# Phishing Email Detection Model

A Machine Learning-based cybersecurity project built using Python and Scikit-learn to identify phishing emails and distinguish them from legitimate emails.

## Features

- Email text analysis
- URL and suspicious keyword detection
- CountVectorizer feature extraction
- Multinomial Naive Bayes classification
- Phishing and Safe email prediction
- Model accuracy evaluation
- Classification report
- Confusion matrix visualization
- Custom email testing

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Machine Learning
- Natural Language Processing (NLP)

## Machine Learning Workflow

1. Dataset creation and loading
2. Email text preprocessing
3. Feature extraction
4. Training and testing data split
5. Naive Bayes model training
6. Email classification
7. Accuracy evaluation
8. Confusion matrix visualization

## How to Run

Install dependencies:

    pip install -r requirements.txt

Run the model:

    python phishing_detector.py

Enter an email when prompted to test its classification.
